## 一、项目概述

### 1.1 一句话定义

2025 年秋天，玩家刚从计算机系毕业（6 月 28 日拿到学位），搬进了外公留下的老房子。阁楼里有一台 1998 年的老电脑，机箱上贴着一张纸条："不要格式化 C 盘。" 接通电源，屏幕上出现了 BIOS 启动画面…… 玩家要用这台电脑解开外公留下的秘密。

### 1.2 游戏定位

**类型：** 叙事解谜 + 教学模拟

核心理念：这不是一个工具，是一个游戏。玩家坐在自己的房间里，面对一台老电脑，通过操作 BIOS 和 DOS 来完成任务、解锁成就、探索故事。

### 1.3 核心玩法循环

```
     ┌──────────────┐
     │   房间探索    │ ← 点击物品、发现线索
     └──────┬───────┘
            │ 发现软盘
            ▼
     ┌──────────────┐
     │   插入软盘    │ ← 拖拽软盘到软驱
     └──────┬───────┘
            │ 按开机键
            ▼
     ┌──────────────┐
     │   BIOS 启动   │ ← POST 画面、内存检测
     └──────┬───────┘
            │ 进入操作系统/DOS
            ▼
     ┌──────────────┐
     │   终端操作    │ ← 执行命令、读文件、解密
     └──────┬───────┘
            │ 发现新线索
            ▼
     ┌──────────────┐
     │   解开谜题    │ ← 新区域开放、新物品解锁
     └──────────────┘
```

## 三、核心系统设计

### 3.1 BIOS 模拟系统

#### 3.1.1 CPU 寄存器模拟（core/cpu.py）

模拟 x86 实模式下的寄存器组：

| 寄存器类别 | 寄存器 | 用途 |
|-----------|--------|------|
| 通用寄存器 | AX, BX, CX, DX | 通用数据操作，部分有特殊含义（AH/AL 拆分） |
| 变址寄存器 | SI, DI | 源/目的变址 |
| 指针寄存器 | SP, BP | 栈指针、基址指针 |
| 段寄存器 | CS, DS, ES, SS | 代码段、数据段、附加段、栈段 |
| 指令指针 | IP | 当前指令偏移 |
| 标志寄存器 | FLAGS | 状态标志（CF, ZF, SF, OF 等） |

#### 3.1.2 内存模型（core/memory.py）

```
┌─────────────────────────────────────┐ 0xFFFFF (1MB)
│          BIOS ROM 区域              │ 0xF0000-0xFFFFF
├─────────────────────────────────────┤ 0xF0000
│          显存区域 (VGA)             │ 0xA0000-0xBFFFF
├─────────────────────────────────────┤ 0xA0000
│          扩展内存 (可用)            │ 0x10000-0x9FFFF
├─────────────────────────────────────┤ 0x10000
│          中断向量表 (IVT)           │ 0x00000-0x003FF
└─────────────────────────────────────┘ 0x00000
```

- 总容量：1MB（实模式寻址范围）
- 中断向量表（IVT）位于 0x0000-0x03FF，存放 256 个中断向量（每项 4 字节）
- BIOS ROM 模拟为只读区域
- VGA 文本模式显存位于 0xB8000

#### 3.1.3 中断调度器（core/interrupt.py）

中断调度器负责接收中断调用请求，根据中断号分派到对应的服务例程：

```
INT 调用 → 调度器查表 → 路由到对应服务模块
                           ├── INT 10h → int10h.py（视频服务）
                           ├── INT 13h → int13h.py（磁盘服务）
                           ├── INT 14h → int14h.py（串口服务）
                           ├── INT 15h → int15h.py（系统服务）
                           ├── INT 16h → int16h.py（键盘服务）
                           ├── INT 17h → int17h.py（打印机服务）
                           └── INT 1Ah → int1ah.py（时钟服务）
```

中断号与处理函数的映射关系在初始化时注册，支持运行时动态添加。

#### 3.1.4 BIOS 主类（core/bios.py）

BIOS 主类负责：

- POST（加电自检）流程控制
- BIOS Setup 菜单界面管理
- 硬件参数配置（启动顺序、硬盘参数等）
- POST 内存检测动画序列的驱动

### 3.2 虚拟磁盘系统

#### 3.2.1 磁盘类型

| 类型 | 容量 | 用途 |
|------|------|------|
| 3.5 英寸软盘 | 1.44MB | 游戏核心道具，每张包含故事线索 |
| 硬盘 | 1.2GB（模拟） | 主存储设备，包含外公的证据 |

#### 3.2.2 寻址方式

| 方式 | 说明 | 应用场景 |
|------|------|----------|
| CHS | 柱面/磁头/扇区 | 传统 BIOS 中断调用、教学演示 |
| LBA | 逻辑块地址 | 大容量设备、简化计算 |

#### 3.2.3 扇区读写（int13h.py）

通过 INT 13h 中断实现：

- **AH=02h：** 读扇区（指定驱动器、柱面、磁头、扇区号）
- **AH=03h：** 写扇区
- **AH=08h：** 获取驱动器参数
- **AH=41h：** 检查扩展 INT 13h 支持

#### 3.2.4 MBR/分区表（filesystem/mbr.py）

MBR 结构模拟：

| 偏移 | 大小 | 内容 |
|------|------|------|
| 0x000 | 446 字节 | 引导代码 |
| 0x1BE | 16 字节 | 分区表项 1 |
| 0x1CE | 16 字节 | 分区表项 2 |
| 0x1DE | 16 字节 | 分区表项 3 |
| 0x1EE | 16 字节 | 分区表项 4 |
| 0x1FE | 2 字节 | 签名（0x55AA） |

分区表项结构（16 字节）：

| 偏移 | 大小 | 内容 |
|------|------|------|
| 0x00 | 1 字节 | 引导标志（0x80=活动分区） |
| 0x01 | 3 字节 | 起始 CHS 地址 |
| 0x04 | 1 字节 | 分区类型（0x06=FAT16） |
| 0x05 | 3 字节 | 结束 CHS 地址 |
| 0x08 | 4 字节 | 起始 LBA |
| 0x0C | 4 字节 | 分区大小（扇区数） |

隐藏分区设计：硬盘中存在隐藏分区，需要在 BIOS 中修改特定设置或使用 INT 13h 扩展功能才能访问。

### 3.3 文件系统

#### 3.3.1 FAT12 文件系统（filesystem/fat12.py）

软盘使用 FAT12 文件系统，核心结构：

| 组件 | 说明 |
|------|------|
| BPB（BIOS 参数块） | 每扇区字节数、每簇扇区数、FAT 表数量、根目录项数等 |
| 引导扇区 | 磁盘第 0 扇区，包含 BPB 和引导代码 |
| FAT 表 | 文件分配表，12 位条目，记录簇链 |
| 根目录区 | 固定大小，存放目录项（32 字节/项） |
| 数据区 | 实际文件内容存储 |

目录项结构（32 字节）：

| 偏移 | 大小 | 内容 |
|------|------|------|
| 0x00 | 8 字节 | 文件名 |
| 0x08 | 3 字节 | 扩展名 |
| 0x0B | 1 字节 | 属性 |
| 0x1A | 2 字节 | 起始簇号 |
| 0x1C | 4 字节 | 文件大小 |

#### 3.3.2 FAT16 支持

硬盘分区使用 FAT16 文件系统，与 FAT12 类似但：

- FAT 表使用 16 位条目
- 支持更大分区容量
- BPB 参数略有不同

#### 3.3.3 隐藏分区

硬盘中存在一个隐藏分区（不显示在标准分区表中），存储加密证据文件。解锁条件：
- 在 BIOS Setup 中修改特定设置
- 或使用 INT 13h 扩展功能直接读取隐藏扇区

### 3.4 DOS 终端模拟

#### 3.4.1 命令解析器

终端支持的 DOS 命令：

| 命令 | 功能 | 章节 |
|------|------|------|
| `dir` | 列出目录内容 | 第一章 |
| `type <file>` | 显示文本文件内容 | 第一章 |
| `cd <dir>` | 切换目录 | 第一章 |
| `a:` / `c:` | 切换驱动器 | 第一章 |
| `format c:` | 格式化 C 盘（触发坏结局） | 全程 |
| `fdisk` | 分区管理 | 第三章 |
| `debug` | 调试工具 | 第三章 |

#### 3.4.2 终端状态机

```
关机状态 → POST 启动序列 → BIOS Setup（可选）→ DOS 引导 → 命令行交互
                │                                        │
                └── (可跳过)                              ├── 输入命令
                                                          └── 输出结果
```

#### 3.4.3 终端渲染规格

- **分辨率：** 80 列 x 25 行文本
- **字体：** VGA 8x16 像素字体
- **调色板：** 标准 VGA 16 色
- **光标：** 闪烁动画，53ms 周期
- **滚屏：** 逐行上滚效果

## 四、游戏系统设计

### 4.1 场景/房间系统

#### 4.1.1 场景总览

游戏共有 **3 个可探索区域**，随剧情推进解锁：

```
┌─────────────────────────────────────────────┐
│              主场景：阁楼房间                 │
│  ┌──────┐  ┌──────┐  ┌──────┐              │
│  │ 窗户 │  │ 书架 │  │ 门   │              │
│  └──────┘  └──────┘  └──────┘              │
│                                             │
│  ┌──────────────────────────┐              │
│  │        书桌区域           │  ← 主交互区   │
│  │  CRT │ 键盘 │ 软驱      │              │
│  └──────────────────────────┘              │
│                                             │
│  [解锁] 地板暗格 → 地下室                   │
│  [解锁] 抽屉夹层 → 密码本                   │
└─────────────────────────────────────────────┘
```

| 区域 | 解锁章节 | 描述 |
|------|----------|------|
| **阁楼房间** | 开局可用 | 斜屋顶阁楼，月光小窗，书桌与 CRT 电脑为核心 |
| **地下室** | 第三章 | 贴满代码图表的墙壁，286 电脑，文件柜 |
| **暗室** | 隐藏结局条件 | 书架后的暗门，只有一台电脑 |

#### 4.1.2 场景切换机制

- 场景切换通过点击门、暗格等交互点触发
- 切换时播放过渡动画（淡入淡出）
- 场景状态（物品位置、解锁进度）持久化保存

#### 4.1.3 阁楼房间 — 可交互物品

| 物品 | 交互方式 | 功能 |
|------|----------|------|
| CRT 显示器 | 点击 | 进入终端视角（画面放大到 CRT 屏幕） |
| 电源按钮 | 点击 | 开机/关机 |
| 软驱 | 点击/拖拽 | 插入/弹出软盘 |
| 键盘 | 点击 | 放大输入区域 |
| 台灯 | 点击/拖拽滑块 | 开关及亮度调节 |
| 书架 | 点击 | 查看书籍，获取知识卡片与线索 |
| 软盘堆 | 点击 | 选择要使用的软盘 |
| 抽屉 | 点击 | 发现软盘和钥匙 |
| 笔记本 | 点击 | 查看/记录线索 |
| 墙上日历 | 点击 | 查看日期，发现线索标记 |
| 窗户 | 点击 | 查看窗外景色（随时间变化） |
| 墙上海报 | 点击 | 隐藏线索和彩蛋 |
| 地板暗格 | 第二章解锁 | 找到硬盘钥匙和信件 |
| 机箱内部 | 第三章解锁 | 硬盘、内存条可交互 |

#### 4.1.4 时间/天气系统

| 时段 | 视觉效果 | 环境音效 |
|------|----------|----------|
| 黄昏 (17:00-19:00) | 橙色光线从窗户射入 | 远处的鸟鸣 |
| 夜晚 (19:00-05:00) | 月光、CRT 发光为主要光源 | 风声、木板吱呀声 |
| 深夜 (00:00-04:00) | 房间更暗，CRT 更醒目 | 钟声（整点） |

#### 4.3.1 任务类型

#### 4.3.2 章节结构

| 章节 | 主题 | 预计时长 | 解锁区域 | 涉及软盘 |
|------|------|----------|----------|----------|

| 第二章：磁盘考古 | 磁盘读写、隐藏扇区、数据恢复 | 45-60 分钟 | 阁楼房间 | DISK_04, 05, 06 |

#### 4.3.3 任务触发条件

任务状态转换遵循以下模式：

```
发现条件满足 → 任务激活 → 完成条件检测 → 任务完成 → 下一任务激活
```

触发条件包括：
- 点击特定物品
- 阅读特定文件
- 执行特定 DOS 命令
- 进入特定区域
- 收集达到特定数量

## 六、教程系统

### 6.1 教学设计理念

**核心原则：**
- **做中学** — 边玩边学，不读说明书
- **渐进式** — 每次只教一个新概念
- **可跳过** — 老手可以跳过所有教程
- **情境化** — 教学融入剧情

### 6.2 四层教学系统

| 层级 | 名称 | 触发条件 | 特点 |
|------|------|----------|------|
| 1 | 强制教学 | 第一次遇到 | 屏幕变暗，步骤指引，必须完成 |
| 2 | 引导教学 | 第二次遇到 | 提示气泡，可选择"我知道了"跳过 |
| 3 | 被动教学 | 随时可查 | 知识卡片、笔记本、按 H 键帮助 |
| 4 | 主动探索 | 高级玩家 | 无提示，成就"硬核模式"奖励 |

### 6.3 教学 UI 元素

| 元素 | 用途 |
|------|------|
| 提示气泡 | 简短说明 + 指向相关 UI |
| 高亮框 | 屏幕变暗，焦点在目标元素 |
| 步骤指示器 | 显示当前步骤进度 (3/7) |
| 帮助面板 | 按 H 键呼出，显示当前任务和操作 |

### 6.4 卡住检测系统

玩家在某任务停留超过 5 分钟时触发：

| 提示等级 | 内容示例 |
|----------|----------|
| 轻微 | "密码可能藏在某个地方的文字记录里。" |
| 详细 | "检查墙上的海报和日历，数字线索分散在各处。" |
| 直接 | "密码是 199806。" |

### 6.5 错误操作保护

- 格式化 C 盘时弹出警告，提供"取消"和"我确定"选项
- 确认后进入坏结局路线（"灰飞烟灭"）

### 6.6 第一章教学引导流程（示例）

```
场景 1-1 整理遗物 → 教程：鼠标操作、点击物品
        ↓
场景 1-2 组装电脑 → 教程：认识硬件部件、拖拽操作
        ↓
场景 1-3 发现软盘 → 知识卡片：《什么是 BIOS？》
        ↓
场景 1-4 第一次启动 → 教程：POST 概念、按 DEL 进入 BIOS
        ↓
场景 1-5 BIOS Setup → 教程：方向键导航、修改启动顺序
        ↓
场景 1-6 DOS 初体验 → 教程：dir、type 命令
        ↓
场景 1-7 阅读信件 → 教程：切换驱动器、继续探索
```
