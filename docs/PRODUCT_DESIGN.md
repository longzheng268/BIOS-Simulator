# x86 BIOS Simulator — 产品设计文档

> **核心理念：** 这不是一个工具，是一个游戏。玩家坐在自己的房间里，面对一台老电脑，通过操作 BIOS 和 DOS 来完成任务、解锁成就、探索故事。

---

## 一、游戏概念

### 一句话定义

> 2025 年秋天，你刚从计算机系毕业（6 月 28 日拿到学位），搬进了外公留下的老房子。阁楼里有一台 1998 年的老电脑，机箱上贴着一张纸条："不要格式化 C 盘。" 接通电源，屏幕上出现了 BIOS 启动画面…… 你要用这台电脑解开外公留下的秘密。

### 游戏类型

**叙事解谜 + 教学模拟**

类似参考：
- **Her Story** — 面对电脑屏幕交互
- **Orwell** — 通过电脑终端完成任务
- **Papers, Please** — 在限定界面中完成操作
- **PC Building Simulator** — 电脑主题

### 游戏画面分层

| 层级 | 内容 | 渲染方式 |
|------|------|----------|
| **最底层** | 房间背景（墙壁、窗户、书架） | 2D 精灵图 / 像素画 |
| **中间层** | CRT 显示器外壳（带弧度、扫描线效果） | 精灵图 + shader |

| **UI 层** | 鼠标光标、物品提示框、任务面板 | GUI 组件 |

## 二、游戏循环

```
     ┌──────────────┐
     │   房间探索    │ ← 点击物品、发现线索
     └──────┬───────┘
            │ 发现软盘
            ▼
     ┌──────────────┐
     │   插入软盘    │ ← 拖拽软盘到软驱
     └──────┬───────┘
            │ 按开机键
            ▼
     ┌──────────────┐
     │   BIOS 启动   │ ← POST 画面、内存检测
     └──────┬───────┘
            │ 进入操作系统/DOS
            ▼
     ┌──────────────┐
     │   终端操作    │ ← 执行命令、读文件、解密
     └──────┬───────┘
            │ 发现新线索
            ▼
     ┌──────────────┐
     │   解开谜题    │ ← 新区域开放、新物品解锁
     └──────────────┘
```

### 示例关卡流程

**第一章：启动**

1. 玩家在房间内探索，发现抽屉里有一张软盘
2. 点击软盘 → 拖到电脑软驱
3. 点击电源按钮 → 电脑启动
4. 观看 POST 启动画面（教学：BIOS 是什么）
5. 进入 BIOS Setup → 修改启动顺序（教学：BIOS 设置）
6. 从软盘启动 → 进入 DOS
7. 执行 `dir` 查看文件 → 发现一个神秘文本文件
8. 用 `type readme.txt` 阅读 → 获得线索

**第二章：磁盘考古**

1. 发现更多软盘，逐一读取
2. 发现加密文件，需要在 BIOS 中修改设置才能读取
3. 学习 INT 13h 中断调用来恢复损坏的扇区
4. 解开隐藏的分区表信息

**第三章：系统恢复**

1. 硬盘损坏，需要修复 MBR
2. 学习 FAT12 文件系统原理
3. 手动重建文件分配表
4. 恢复关键文件，揭开故事真相

## 三、游戏系统

### 3.1 房间探索系统

| 可交互物品 | 功能 |
|------------|------|
| CRT 显示器 | 显示 BIOS 终端内容 |
| 键盘 | 输入文字/命令 |
| 电源按钮 | 开机/关机 |
| 软驱 | 插入/弹出软盘 |
| 硬盘（机箱内） | 查看硬盘状态、损坏程度 |
| 台灯 | 调节亮度 |
| 软盘堆 | 选择要使用的软盘 |
| 笔记本 | 记录已发现的线索 |
| 书架 | 学习资料（可查看 BIOS 知识卡片） |
| 墙上日历 | 显示游戏内时间 |
| 窗户 | 显示白天/黑夜变化 |

### 3.2 终端系统（嵌套的 BIOS 界面）

终端区域是游戏的核心，位于 CRT 显示器精灵图内部：

```
┌────────────────────────────────────────────┐
│  CRT显示器外壳精灵图                        │
│  ┌──────────────────────────────────────┐  │
│  │ 扫描线效果 (shader)                   │  │
│  │ 微妙的屏幕弧度 (shader)               │  │
│  │ ┌──────────────────────────────────┐ │  │
│  │ │                                  │ │  │
│  │ │   BIOS 终端渲染区域               │ │  │
│  │ │   (VGA 字体, 80×25 文本)         │ │  │
│  │ │                                  │ │  │
│  │ │   - 光标闪烁动画                  │ │  │
│  │ │   - 16色显示                      │ │  │
│  │ │   - 滚屏效果                      │ │  │
│  │ │                                  │ │  │
│  │ └──────────────────────────────────┘ │  │
│  │ 屏幕边框阴影                         │  │
│  └──────────────────────────────────────┘  │
│  CRT外壳高光                              │
└────────────────────────────────────────────┘
```

**终端支持的操作：**

| 状态 | 内容 | 用户操作 |
|------|------|----------|
| 关机 | 黑屏 + 电源灯 | 点击电源按钮开机 |
| POST | 内存检测滚动文字 | 观看（可跳过） |
| BIOS Setup | 蓝色背景菜单 | 方向键导航、回车确认、Esc 返回 |
| DOS 启动 | 启动信息 | 等待命令提示符 |
| DOS 命令行 | `C:\>` 提示符 | 键入命令并回车 |
| 中断调用 | 无显示 | 在教学模式中显示 |

| CHS 寻址 | 柱面/磁头/扇区 | 磁盘操作 |
| 文件系统入门 | FAT12 原理 | 读取软盘 |

## 五、开发阶段

### 阶段 1：CRT 终端（1-2 周）

**目标：** 把 BIOS 终端嵌入 pygame 窗口，带 CRT 特效

- [ ] 搭建游戏主窗口（1280×720）
- [ ] 渲染 CRT 显示器精灵图
- [ ] 在 CRT 区域内渲染 VGA 终端（80×25）
- [ ] 扫描线效果（半透明横线叠加）
- [ ] 屏幕弧度效果（像素偏移）
- [ ] VGA 16 色调色板
- [ ] 光标闪烁动画（53ms 周期）
- [ ] 键盘输入 → 终端输入映射

**里程碑：** 能看到 CRT 效果的 BIOS 屏幕，可以输入文字。

### 阶段 2：房间场景（2-3 周）

**目标：** 完整的游戏房间，可交互物品

- [ ] 房间背景渲染（像素画风格）
- [ ] 物品悬停高亮效果
- [ ] 物品点击交互
- [ ] 软盘拖拽到软驱
- [ ] 电源按钮（开机/关机动画）
- [ ] 台灯亮度调节
- [ ] 房间昼夜变化
- [ ] 环境音效（风声、钟声）

**里程碑：** 能在房间内探索、拖拽软盘、开机。

### 阶段 3：BIOS + DOS 体验（3-4 周）

**目标：** 完整的 BIOS 操作 + DOS 命令行

- [ ] BIOS Setup 菜单（蓝色界面、方向键导航）
- [ ] POST 启动序列（内存检测滚动）
- [ ] DOS 命令行模式
- [ ] dir, type, cd 等基础 DOS 命令
- [ ] INT 13h 磁盘读写
- [ ] 软盘文件读取（FAT12）
- [ ] BIOS 教学提示（首次操作时弹出知识卡片）

**里程碑：** 从开机 → POST → BIOS Setup → DOS → 读取文件，完整流程。

### 阶段 4：游戏内容（3-4 周）

**目标：** 故事、任务、成就

- [ ] 任务系统（主线 + 支线）
- [ ] 3-5 章主线故事
- [ ] 知识卡片收集系统（10+张）
- [ ] 存档/读档系统
- [ ] Steam 成就集成
- [ ] 结局系统（至少 2 个结局）

**里程碑：** 有完整故事线，可通关，可收集。

### 阶段 5：打磨 + 上架（2-3 周）

**目标：** Steam 上架

- [ ] UI 美化、动效完善
- [ ] 音乐音效完善

- [ ] 兼容性测试（不同分辨率）

- [ ] 打包 + 发布

## 十、新手教学引导系统

### 10.1 教学设计理念

**核心原则：**
- **做中学** — 边玩边学，不读说明书
- **渐进式** — 每次只教一个新概念
- **可跳过** — 老手可以跳过所有教程
- **情境化** — 教学融入剧情

### 10.2 四层教学系统

| 层级 | 名称 | 触发条件 | 特点 |
|------|------|----------|------|
| 1 | 强制教学 | 第一次遇到 | 屏幕变暗，步骤指引，必须完成 |
| 2 | 引导教学 | 第二次遇到 | 提示气泡，可选择"我知道了"跳过 |
| 3 | 被动教学 | 随时可查 | 知识卡片、笔记本、按 H 键帮助 |
| 4 | 主动探索 | 高级玩家 | 无提示，成就"硬核模式"奖励 |

### 10.3 教学 UI 元素

| 元素 | 用途 |
|------|------|
| 提示气泡 | 简短说明 + 指向相关 UI |
| 高亮框 | 屏幕变暗，焦点在目标元素 |
| 步骤指示器 | 显示当前步骤进度 (3/7) |
| 帮助面板 | 按 H 键呼出，显示当前任务和操作 |

### 10.4 卡住检测系统

玩家在某任务停留超过 5 分钟时触发：

| 提示等级 | 内容示例 |
|----------|----------|
| 轻微 | "密码可能藏在某个地方的文字记录里。" |
| 详细 | "检查墙上的海报和日历，数字线索分散在各处。" |
| 直接 | "密码是 199806。" |

### 10.5 错误操作保护

- 格式化 C 盘时弹出警告，提供"取消"和"我确定"选项
- 确认后进入坏结局路线（"灰飞烟灭"）

### 11.2 剧情关键节点

### 11.5 扩展对话系统

#### 11.5.1 张阿姨（邻居）对话线

张阿姨是外公的老邻居，20 多年来一直住在对面。她知道一些外公的往事，需要玩家多次拜访才能慢慢打开话匣子。

| 次数 | 触发条件 | 关键信息 |
|------|----------|----------|
| 第一次 | 第二章开始 | 外公从辛巳游戏工作室辞职后变得孤僻 |
| 第二次 | 收集 2+ 数据碎片 | 1998 年有穿西装的人来找外公（李德胜特征） |
| 第三次 | 证据解密后 | 张阿姨保管着外公留下的信封（暗室钥匙线索） |
| 第四次 | 隐藏结局后 | 感谢与祝福 |

#### 11.5.2 李德胜"幽灵电话"系统

老式电话机在特定剧情节点响起，是李德胜多年前留下的录音或实时通话。

| 次数 | 触发条件 | 内容摘要 |
|------|----------|----------|
| 第一次 | 第 3 个数据碎片 | 威胁外公交出证据 |
| 第二次 | MBR 修复后 | 承认贪污，暗示"有人顶罪" |
| 第三次 | 找到所有密码 | 慌张，承认暗室里有他害怕的东西 |

#### 11.5.3 玩家选择分支（4个关键节点）

虽然主线真相固定，但玩家的态度影响结局呈现：

| 分支点 | 选择 | 影响 |
|--------|------|------|
| 是否信任张阿姨 | 信任/谨慎 | 影响后续对话深度 |

| 证据如何处理 | 交给警方/打开暗室/放弃 | 影响结局走向 |
| 暗室门前 | 进入/犹豫/查看线索 | 影响隐藏结局达成 |
