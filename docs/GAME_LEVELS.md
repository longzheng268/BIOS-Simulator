# x86 BIOS Simulator — 关卡与场景详细设计

> 本文档是游戏关卡、场景、谜题、剧情的完整设计。

---

## 一、故事背景

### 主线剧情

**时间：** 2025 年秋

**设定：** 玩家于 2025 年 6 月 28 日从计算机系毕业。三个月后的秋天，搬进了外公留下的老房子。外公曾是 90 年代的程序员，在一家名为"辛巳游戏工作室"的小公司工作。公司在 1998 年神秘关闭，外公从此再没提过那段经历。

**玩家背景：**
- 2021 年入学，计算机科学与技术专业
- 2025 年 6 月 28 日毕业
- 对底层系统（操作系统、汇编、BIOS）有基础了解
- 刚找到工作，等待入职，有几个月空闲时间

**第一章发现：** 在阁楼整理遗物时，玩家发现一台 1995 年的老电脑，机箱上贴着一张纸条："**不要格式化 C 盘。**"

### 故事悬念

| 线索来源 | 悬念 |
|----------|------|
| 软盘中的日记 | 外公在调查公司内部的某个秘密项目 |
| 硬盘中的加密文件 | 有一份关键证据被分段隐藏在不同扇区 |
| 笔记本中的手写密码 | 需要在 BIOS 中输入特定设置才能解锁 |
| 书架上的技术手册 | 外公留下了解密的线索 |
| 墙上日历的标记 | 某个日期反复出现——真相揭开的日子 |

### 三个结局

| 结局 | 条件 | 内容 |
|------|------|------|
| **普通结局** | 完成主线 | 发现外公是无辜的，公司关闭另有隐情 |
| **隐藏结局** | 完成主线 + 收集所有软盘 + 找到所有密码 | 揭开完整真相，外公留下了一段加密视频 |
| **彩蛋结局** | 在特定时间（1998年6月15日）启动电脑 | 显示外公的最终信息："你找到了，孩子。" |

## 二、房间场景设计

### 场景总览

游戏共有 **3 个可探索区域**，随剧情推进解锁：

```
┌─────────────────────────────────────────────┐
│              主场景：阁楼房间                 │
│  ┌──────┐  ┌──────┐  ┌──────┐              │
│  │ 窗户 │  │ 书架 │  │ 门   │              │
│  └──────┘  └──────┘  └──────┘              │
│                                             │
│  ┌──────────────────────────┐              │
│  │        书桌区域           │  ← 主交互区   │
│  │  CRT │ 键盘 │ 软驱      │              │
│  └──────────────────────────┘              │
│                                             │
│  [解锁] 地板暗格 → 地下室                   │
│  [解锁] 抽屉夹层 → 密码本                   │
└─────────────────────────────────────────────┘
```

### 2.1 主场景：阁楼房间

#### 环境描述

> 阁楼不大，斜屋顶上有一扇小窗。月光透过玻璃照进来，在木地板上投下一片银白。角落里堆着几个纸箱，墙上挂着几幅旧海报——90 年代的科幻电影、摇滚乐队。正中央是一张老式书桌，上面摆着一台米白色的 CRT 电脑。机箱已经泛黄，键盘上的字母有些磨损。

#### 天气/时间系统

| 时段 | 视觉效果 | 环境音效 |
|------|----------|----------|
| 黄昏 (17:00-19:00) | 橙色光线从窗户射入 | 远处的鸟鸣 |
| 夜晚 (19:00-05:00) | 月光、CRT 发光为主要光源 | 风声、木板吱呀声 |
| 深夜 (00:00-04:00) | 房间更暗，CRT 更醒目 | 钟声（整点） |
| 清晨 (05:00-07:00) | 晨光逐渐亮起 | 鸟鸣、远处车声 |

房间时间随真实时间变化，也受主线进度影响（关键剧情会强制切换到夜晚）。

#### 可交互物品详细设计

**【书桌 — CRT 显示器】**

| 状态 | 交互 | 效果 |
|------|------|------|
| 关机 | 点击 | 显示"没有电源" |
| 开机后 | 点击 | 进入终端视角（画面放大到 CRT 屏幕） |
| POST 中 | 点击 | 跳过 POST 动画 |
| BIOS Setup | 操作 | 方向键导航、回车确认、Esc 返回 |

**【书桌 — 电源按钮】**

| 条件 | 交互 | 效果 |
|------|------|------|
| 无软盘 | 点击 | 电脑启动后提示"No bootable device"，自动关机 |
| 有软盘 | 点击 | POST 动画 → 从软盘启动 DOS |
| 有硬盘软盘 | 点击 | 从硬盘启动（需修复 MBR 后才能成功） |

**【书桌 — 软驱】**

| 交互 | 效果 |
|------|------|
| 点击软驱 | 打开/关闭软驱门 |
| 拖拽软盘 → 软驱 | 插入软盘，显示软盘名称（如"DISK_01"） |
| 点击已插入的软盘 | 弹出软盘 |

**【书桌 — 键盘】**

| 交互 | 效果 |
|------|------|
| 悬停 | 高亮，显示"键盘 — 点击输入" |
| 点击 | 键盘区域放大，可以键入命令 |
| 电脑开机时 | 按键有声音反馈 |

**【书桌 — 台灯】**

| 交互 | 效果 |
|------|------|
| 点击 | 开/关台灯 |
| 拖拽滑块 | 调节亮度（影响房间光照和 CRT 可见度） |

**【书架】**

| 交互 | 效果 |
|------|------|
| 点击 | 打开书架视图，显示可用书籍 |
| 点击书籍 | 翻阅书籍，获取知识卡片或剧情线索 |

书架上的书籍：

| 书名 | 内容 | 章节解锁 |
|------|------|----------|
| 《x86 入门》 | BIOS 基础概念 | 第一章 |
| 《汇编语言》 | 寄存器、指令 | 第一章 |
| 《DOS 操作指南》 | DOS 命令参考 | 第二章 |
| 《磁盘结构》 | MBR/FAT12 原理 | 第三章 |
| 《加密与解密》 | 简单加密算法 | 第四章 |

**【墙上日历】**

| 交互 | 效果 |
|------|------|
| 点击 | 查看日历，显示游戏内日期 |
| 特定日期 | 有红圈标记（1998-06-15 反复出现） |

**【窗户】**

| 交互 | 效果 |
|------|------|
| 点击 | 查看窗外景色（随时间变化） |
| 特定时间 | 可看到邻居窗户亮灯（暗示有邻居存在） |

**【墙上海报】**

| 海报 | 内容 |
|------|------|
| 《黑客帝国》 | 隐藏彩蛋：特定角度看到代码 |
| 《2001太空漫游》 | 外公的兴趣爱好暗示 |
| 辛巳游戏工作室海报 | 公司 Logo，背面有手写数字（密码线索） |

**【软盘堆】**

| 状态 | 内容 |
|------|------|
| 初始 | 只有 1 张软盘（DISK_01） |
| 第一章后 | +2 张（DISK_02, DISK_03） |
| 第二章后 | +3 张（DISK_04, DISK_05, DISK_06） |
| 第三章后 | +2 张（DISK_07, DISK_08） |
| 支线完成 | +1 张（DISK_SECRET — 彩蛋盘） |

**【抽屉】**

| 交互 | 效果 |
|------|------|
| 点击上层抽屉 | 找到软盘 DISK_01 |
| 点击下层抽屉 | 需要钥匙（第一章任务） |
| 打开下层 | 找到笔记本 + 钥匙串 |

**【笔记本】**

| 交互 | 效果 |
|------|------|
| 点击 | 打开笔记本，查看已收集的线索 |
| 新线索发现 | 自动添加到笔记本 |
| 可手动记录 | 玩家可以在笔记本上写笔记（保存文字） |

**【地板暗格 — 第二章解锁】**

| 交互 | 效果 |
|------|------|
| 发现线索前 | 无法交互 |
| 发现线索后 | 点击地板松动处，打开暗格 |
| 暗格内 | 找到硬盘（机箱内）的钥匙 + 一封信 |

**【机箱内部 — 第三章解锁】**

| 交互 | 效果 |
|------|------|
| 第三章前 | 机箱封死 |
| 获得钥匙后 | 打开机箱，看到硬盘、内存条、主板 |
| 硬盘 | 显示损坏程度（0%-100%），可交互修复 |
| 内存条 | 点击可查看/移除/插入（教学用途） |

### 2.2 副场景：地下室（第三章解锁）

#### 环境描述

> 通往地下室的门在阁楼角落。门上的锁已经生锈，需要用力才能推开。地下室比阁楼大一些，墙上贴满了手写的代码和图表。角落里有一个文件柜，里面塞满了软盘和文档。桌上放着一台更老的电脑——286。

#### 可交互物品

| 物品 | 内容 |
|------|------|
| 286 电脑 | 可以启动，运行更简化的 BIOS（教学用途） |
| 文件柜 | 存放更多软盘和手写文档 |
| 墙上图表 | 外公手绘的系统架构图（知识卡片来源） |
| 文件柜抽屉 A | 第四章密码本 |
| 文件柜抽屉 B | 外公的工作日志（剧情） |
| 纸箱 | 老照片、公司文件、外公的工作证 |

### 2.3 副场景：阁楼暗室（隐藏结局解锁）

#### 解锁条件

收集全部 8 张软盘 + 找到全部 5 个密码。

#### 环境描述

> 书架后面有一面镜子，当你把所有线索输入电脑后，镜子后面的墙壁打开了一扇暗门。暗室很小，只有一台电脑和一张椅子。电脑屏幕上显示着一行字："等待输入密钥……"

#### 互动

| 物品 | 内容 |
|------|------|
| 暗室电脑 | 输入最终密钥，播放加密视频（隐藏结局） |
| 墙上照片 | 外公和团队的合影 |
| 桌上信封 | 最后一封信 — 外公写给玩家的信 |

## 三、章节详细设计

---

### 第一章：发现

**主题：** BIOS 入门、POST 流程、基本操作
**预计时长：** 30-45 分钟
**解锁区域：** 阁楼房间
**软盘：** DISK_01, DISK_02, DISK_03

---

#### 场景 1-1：整理遗物

**触发条件：** 游戏开始

**环境：** 黄昏，阁楼房间。箱子还没打开，书桌上空空如也（电脑还没摆上去）。

**交互流程：**

1. 阅读开场文字（外公去世的消息，玩家搬进老房子）
2. 自由探索阁楼（教程引导：如何移动鼠标、点击物品）
3. 点击箱子 → 打开第一个箱子，找到键盘、鼠标
4. 点击箱子 → 打开第二个箱子，找到 CRT 显示器和机箱
5. 自动摆放到书桌上

**知识卡片解锁：** 无

**任务更新：** "把电脑组装起来"

---

#### 场景 1-2：组装电脑

**触发条件：** 场景 1-1 完成

**交互流程：**

1. 点击机箱 → 打开机箱侧板（展示内部结构）
2. 教程弹出：认识主板、CPU、内存、硬盘、显卡
3. 拖拽内存条 → 插入内存插槽（自动对齐）
4. 拖拽显卡 → 插入 PCI 插槽
5. 连接显示器线缆（拖拽 VGA 线到接口）
6. 连接键盘线缆（拖拽 PS/2 线到接口）
7. 关闭机箱侧板

**知识卡片解锁：** 《电脑硬件基础》（认识各部件）

**任务更新：** "找找周围有没有软盘"

---

#### 场景 1-3：发现软盘

**触发条件：** 场景 1-2 完成

**交互流程：**

1. 点击书桌抽屉（上层）→ 找到一张软盘
2. 软盘标签手写着："DISK_01 — 给未来的你"
3. 阅读抽屉里的纸条："不要格式化 C 盘。——外公"
4. 知识卡片弹出：《什么是 BIOS？》

**知识卡片解锁：** 《什么是 BIOS？》

**任务更新：** "把软盘放进软驱，然后开机"

---

#### 场景 1-4：第一次启动

**触发条件：** 场景 1-3 完成，软盘已插入

**这是游戏的核心教学关卡。**

**交互流程：**

1. 点击软驱 → 拖拽 DISK_01 到软驱
2. 点击电源按钮 → 电脑启动

**CRT 显示器亮起 — POST 动画开始：**

```

Copyright (C) 1984-96, Award Software, Inc.

Intel Pentium(R) Processor  133MHz

Memory Test :   128K OK

3. 教程弹出："这就是 POST（加电自检）。BIOS 会检查硬件是否正常。"
4. 倒计时出现："3 秒后自动进入 BIOS Setup..."
5. 按 DEL 键 → 进入 BIOS Setup（教学：按 DEL 进入设置）

**知识卡片解锁：** 《POST 启动流程》

#### 场景 1-5：BIOS Setup 入门

**触发条件：** 场景 1-4 完成

**CRT 显示器显示 BIOS Setup 界面（蓝色背景，灰色文字）：**

```
┌─────────────────────────────────────────────────────┐
│  CMOS SETUP UTILITY - AWARD SOFTWARE                │
│  Copyright (C) 1984-96, Award Software, Inc.        │
├─────────────────────────────────────────────────────┤
│                                                     │
│   STANDART CMOS SETUP        BIOS FEATURES SETUP   │
│   CHIPSET FEATURES SETUP     POWER MANAGEMENT       │
│   PNP/PCI CONFIGURATION      INTEGRATED PERIPHERALS │
│   LOAD BIOS DEFAULTS         LOAD SETUP DEFAULTS    │
│   SUPERVISOR PASSWORD        USER PASSWORD          │
│   IDE HDD AUTO DETECTION     SAVE & EXIT SETUP      │
│   EXIT WITHOUT SAVING                               │
│                                                     │
├─────────────────────────────────────────────────────┤
│  ↑↓←→ : Select    Enter : Accept    Esc : Exit     │
└─────────────────────────────────────────────────────┘
```

**教程引导：**

1. 用方向键移动光标到 "STANDART CMOS SETUP"
2. 按回车进入 → 显示日期、时间、硬盘参数
3. 教程："这是标准 CMOS 设置，可以修改系统时间和硬件参数。"
4. 按 Esc 返回
5. 移动到 "BIOS FEATURES SETUP" → 回车
6. 找到 "Boot Sequence" 选项
7. 教程："启动顺序决定了电脑从哪个设备启动。我们改成从软盘启动。"
8. 用 PageUp/PageDown 切换到 "A, C, SCSI"
9. 按 Esc 返回主菜单
10. 移动到 "SAVE & EXIT SETUP" → 回车 → 输入 "Y" 确认

**知识卡片解锁：** 《BIOS Setup 详解》

**任务更新：** "等待电脑从软盘启动进入 DOS"

### 9.1 教学设计理念

**核心原则：**
- **做中学** — 不读说明书，边玩边学
- **渐进式** — 每次只教一个新概念
- **可跳过** — 老手可以跳过所有教程
- **情境化** — 教学融入剧情，不是硬塞

> 图灵完备做的是"从逻辑门造CPU"。我们不做这个。
> 我们做的是**从磁盘取证到 BIOS 编程到数据恢复**——
> 这些是图灵完备完全没有的领域，是真正的"计算机考古"。

## A、设计理念：与图灵完备的差异

| 维度 | 图灵完备 | 本游戏（硬核模式） |
|------|----------|-------------------|
| 焦点 | CPU 架构 | 磁盘取证 + BIOS 编程 + 数据恢复 |
| 操作层 | 电路层 | 端口 I/O + 汇编 + 文件系统 |
| 玩法 | 搭建 → 测试 → 验证 | 发现 → 分析 → 恢复 → 解密 |
| 叙事 | 无 | 有（外公的调查故事） |
| 成就感 | "我的 CPU 能跑了" | "我恢复了被销毁的证据" |

**我们的独特定位：** 让玩家成为**数字考古学家**，用 BIOS 中断和汇编语言挖掘、恢复、解密被隐藏的数据。

## C、取证模式详细设计

> 玩家扮演 90 年代的数字取证专家，任务是**从被故意销毁的磁盘中恢复证据**。

#### 关卡 3-1：写一个引导扇区

```
任务：写一个 512 字节的引导扇区程序。

org 0x7C00

start:
    ; 设置段寄存器
    MOV AX, 0x0000
    MOV DS, AX
    MOV ES, AX
    MOV SS, AX
    MOV SP, 0x7C00

    ; 显示欢迎信息
    MOV SI, msg_welcome
    CALL print_string

.wait_key:
    ; 等待按键
    MOV AH, 0x00
    INT 16h

    CMP AL, '1'
    JE .demo_video
    CMP AL, '2'
    JE .demo_disk
    CMP AL, '3'
    JE .demo_exit
    JMP .wait_key

.demo_video:
    ; TODO: 视频模式演示
    JMP .wait_key

.demo_disk:
    ; TODO: 磁盘读取演示
    JMP .wait_key

.demo_exit:
    MOV SI, msg_bye
    CALL print_string
    HLT

print_string:
    LODSB
    OR AL, AL
    JZ .done
    MOV AH, 0x0E
    MOV BH, 0
    INT 10h
    JMP print_string
.done:
    RET

msg_welcome: db 'Boot Sector Demo v1.0', 13, 10
             db '1-Video  2-Disk  3-Exit', 13, 10, 0
msg_bye:     db 'Goodbye!', 13, 10, 0

; 填充到 510 字节
times 510-($-$$) db 0
